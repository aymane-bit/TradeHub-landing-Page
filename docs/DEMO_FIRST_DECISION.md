# Demo-first conversion decision

Date: 2026-09-21

TradeHub no longer uses an early-access or waitlist conversion. The public website now
directs visitors to a no-registration, isolated, simulated product demo. Historical
task reports may describe the superseded early-access direction.

Task 006 creates `/demo` only as a truthful static development handoff so links resolve.
It does not select an architecture, integrate the real application, show fake product
behavior, collect information, or connect production services. The page must be
replaced before public launch.

Tasks 007–010 are governed by the demo contract in `PROJECT_BRIEF.md` and
`IMPLEMENTATION_PLAN.md`. Task 007 audits the real application and its security and data
boundaries before any architecture is selected.
